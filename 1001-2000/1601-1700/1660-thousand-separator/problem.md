# Thousand Separator

Source: [https://leetcode.com/problems/thousand-separator/](https://leetcode.com/problems/thousand-separator/)

<!-- leetlore-submission-id: 1401658540 -->

Given an integer `n`, add a dot (".") as the thousands separator and return it in string format.

Example 1:

```
Input: n = 987
Output: "987"
```

Example 2:

```
Input: n = 1234
Output: "1.234"
```

Constraints:

- `0 <= n <= 2^31 - 1`
